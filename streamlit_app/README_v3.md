# 🔌 Анализатор электронных схем v3.0

## 🎯 Новый интерфейс с управлением проектами

### 📋 Основные возможности:

#### **1️⃣ Левая панель - Дерево проектов**
- **Создание проектов:** Организация схем по папкам
- **Загрузка файлов:**
  - 📄 **Netlist** (.txt, .net, .cir)
  - 📋 **Требования** (.txt, .md) 
  - 📊 **Спецификация/BOM** (.csv, .xlsx, .txt)
  - 📕 **PDF схемы** (.pdf)
- **Навигация:** Двухуровневая структура (проект → файлы)

#### **2️⃣ Центральная область - Просмотр схем**
- **PDF Viewer:** Встроенный просмотр схем из PDF
- **Текстовые файлы:** Отображение netlist и требований
- **Кнопка анализа:** 🚀 Запуск анализа схемы
- **Пустое состояние:** Подсказки для пользователя

#### **3️⃣ Правая панель - Чат с ассистентом**
- **История сообщений:** Сохранение диалога
- **Интерактивный ввод:** Вопросы по схеме
- **Контекст проекта:** Автоматическая привязка к выбранному проекту

#### **4️⃣ Нижняя консоль - Логи системы**
- **Реальное время:** Отслеживание действий пользователя
- **Цветовая индикация:** Ошибки, предупреждения, успех
- **История операций:** Последние 50 сообщений

### 🎨 Дизайн и UX:

#### **✨ Профессиональный внешний вид:**
- Градиентный заголовок
- Цветовая схема с hover-эффектами
- Адаптивная сетка колонок
- Консоль в стиле терминала

#### **🔄 Интерактивность:**
- Выделение выбранных элементов
- Плавные переходы и анимации
- Мгновенная обратная связь
- Автоматическое обновление состояния

### 🚀 Запуск:

```bash
# Активировать виртуальное окружение
source venv/bin/activate

# Запустить интерфейс
streamlit run streamlit_app/app_v3.py --server.port 8501
```

### 📱 Доступ:
**URL:** http://localhost:8501

### 🔧 Технические особенности:

#### **📦 Зависимости:**
- `streamlit` - основной фреймворк
- `PyMuPDF` - просмотр PDF файлов
- `Pillow` - обработка изображений
- `requests` - API интеграция

#### **💾 Состояние сессии:**
- Проекты и файлы сохраняются в session_state
- История чата персистентна
- Логи консоли накапливаются

#### **🎯 Готовые интеграции:**
- Заглушки для LLM API
- Структура для анализа схем
- Система логирования событий

# План экспериментов: LLM-агент vs Эксперты в анализе схем

## Эксперимент 1: Базовый анализ делителей напряжения

### Цель
Отладить концепцию LLM-агента на простейших пассивных схемах

### Методика
1. **Создание тестовых схем делителей**:
   - Различные соотношения R1/R2
   - Разные уровни входного напряжения
   - Практичные и проблемные номиналы

2. **LLM-агент анализ**:
   - Расчет выходного напряжения
   - Оценка тока и мощности
   - Инженерные рекомендации

3. **Эталонный экспертный анализ**:
   - Точные математические расчеты
   - Практические инженерные оценки
   - Выявление потенциальных проблем

### Ожидаемый результат
Базовая валидация концепции LLM-агента на простейших схемах

## Эксперимент 2: Извлечение технических параметров

### Цель
Оценить качество извлечения параметров из текста ТЗ

### Методика
1. **Регулярные выражения** для базовых параметров
2. **NER модель** для сложных случаев
3. **Валидация** извлеченных значений

### Метрики
- Точность извлечения (Precision)
- Полнота извлечения (Recall)
- F1-мера

### Целевые показатели
- Precision > 80%
- Recall > 70%
- F1 > 75%

## Эксперимент 3: Классификация качества ТЗ

### Цель
Автоматическая оценка полноты и качества ТЗ

### Методика
1. **Признаки для классификации**:
   - TF-IDF векторы текста
   - Количественные признаки (длина, параметры)
   - Структурные признаки

2. **Модели для сравнения**:
   - Логистическая регрессия
   - Random Forest
   - SVM

3. **Кросс-валидация** (5-fold)

### Метрики
- Accuracy классификации
- Precision/Recall для каждого класса
- ROC-AUC

### Целевые показатели
- Accuracy > 75%
- F1-macro > 70%

## Эксперiment 4: Генерация рекомендаций

### Цель
Автоматическое создание вопросов для улучшения ТЗ

### Методика
1. **Шаблонная генерация** на основе найденных проблем
2. **Приоритизация** рекомендаций по важности
3. **Экспертная оценка** качества вопросов

### Метрики
- Релевантность вопросов (экспертная оценка)
- Покрытие проблем
- Практическая применимость

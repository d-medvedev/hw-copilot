# Эксперименты LLM-агента для анализа схем

## 🚀 Быстрый старт

### 1. Настройка виртуального окружения

```bash
# Создаем виртуальное окружение
python3 -m venv publication/venv

# Активируем (macOS/Linux)
source publication/venv/bin/activate

# Активируем (Windows)
# publication\venv\Scripts\activate

# Устанавливаем зависимости
pip install --upgrade pip
pip install numpy matplotlib pandas jupyter ipykernel openai python-dotenv
```

### 2. Настройка API ключа

Создайте файл `.env` в корне проекта:
```bash
OPENAI_API_KEY=your_openai_api_key_here
```

### 3. Запуск эксперимента

```bash
# Убедитесь, что виртуальное окружение активировано
source publication/venv/bin/activate

# Запустите эксперимент
python publication/experiments/voltage_divider_experiment.py
```

## 📊 Что делает эксперимент

1. **Создает 5 тестовых делителей напряжения** с разными параметрами
2. **Анализирует каждый делитель двумя способами:**
   - Эталонный экспертный анализ (математически точный)
   - LLM-агент анализ (GPT-4o)
3. **Сравнивает результаты** и выводит метрики:
   - Точность расчетов (ошибки в %)
   - Согласие в итоговых оценках
4. **Сохраняет результаты** в JSON файл

## 📈 Ожидаемые результаты

Эксперимент покажет:
- Насколько точно LLM рассчитывает электрические параметры
- Как хорошо LLM оценивает практичность схемы
- Процент согласия с экспертными заключениями

## ⚠️ Устранение проблем

**Ошибка API ключа:**
- Проверьте файл `.env`
- Убедитесь, что ключ OpenAI действителен

**Ошибки импорта:**
- Убедитесь, что виртуальное окружение активировано
- Переустановите зависимости: `pip install -r requirements.txt`

**Проблемы с JSON парсингом:**
- LLM иногда возвращает невалидный JSON
- Эксперимент автоматически обрабатывает такие случаи

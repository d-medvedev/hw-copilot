# Эксперименты LLM-агента для анализа схем

Этот раздел содержит код и результаты экспериментов по оценке способности LLM-агентов анализировать электронные схемы и выявлять ошибки.

## 🎯 Цель исследования

Оценить способность LLM-агента, оснащенного инженерными инструментами, к анализу электронных схем и выявлению ошибок, сравнивая его результаты с экспертными заключениями.

## 📁 Структура экспериментов

### ✅ Завершенные эксперименты:

#### `divider/` - Делители напряжения
- **Статус:** Завершено ✅
- **Тестовых кейсов:** 10
- **Результаты:** F1-score: 0.61, Precision: 0.64, Recall: 0.58
- **Особенности:** 
  - Поддержка BOM (Bill of Materials)
  - 6 типов ошибок
  - Structured Output для надежного парсинга
  - Температурный анализ компонентов

### 🔄 Планируемые эксперименты:

#### `filters/` - Пассивные фильтры RC/LC
- **Статус:** Планируется
- **Фокус:** Частотные характеристики, АЧХ/ФЧХ
- **Сложность:** Средняя

#### `regulators/` - Линейные стабилизаторы (LDO)
- **Статус:** Планируется  
- **Фокус:** Активные компоненты, стабильность
- **Сложность:** Высокая

#### `converters/` - Импульсные преобразователи
- **Статус:** Планируется
- **Фокус:** Динамические схемы, силовая электроника
- **Сложность:** Очень высокая

## 📊 Методология

### Типы анализируемых ошибок:
1. **Логические** - неправильная логика работы
2. **Топологические** - неправильные соединения
3. **Функциональные** - не выполняет требуемую функцию
4. **Электрические** - нарушение электрических правил
5. **Номиналы** - неправильные значения компонентов
6. **Пропущенные элементы** - отсутствующие компоненты

### Метрики оценки:
- **Precision** - точность обнаружения ошибок
- **Recall** - полнота обнаружения ошибок
- **F1-score** - гармоническое среднее Precision и Recall
- **Cohen's κ** - уровень согласия с экспертом

### Входные данные:
- **Netlist** - SPICE описание схемы
- **BOM** - спецификация компонентов с характеристиками
- **Техническое задание** - требования к схеме

## 🛠️ Инструменты LLM-агента

### Реализованные:
- ✅ **BOM-анализ** - проверка характеристик компонентов
- ✅ **Structured Output** - надежное извлечение результатов

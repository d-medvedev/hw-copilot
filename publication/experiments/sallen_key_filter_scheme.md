# Графическое представление фильтра Саллена-Ки с ошибкой

## Правильная схема фильтра Саллена-Ки нижних частот

```
                    ┌─────────┐
         VIN ───────┤   R1    ├────── N1 ──────┐
                    └─────────┘                │
                                               │
                    ┌─────────┐                │
         N1 ────────┤   C1    ├────── N2 ──────┼─┐
                    └─────────┘                │ │
                                               │ │
                    ┌─────────┐                │ │
         N2 ────────┤   R2    ├────── N3 ──────┼─┼─┐
                    └─────────┘                │ │ │
                                               │ │ │
                    ┌─────────┐                │ │ │
         N3 ────────┤   C2    ├────── 0 (GND)  │ │ │
                    └─────────┘                │ │ │
                                               │ │ │
         ┌─────────────────────────────────────┘ │ │
         │                                       │ │
         │  ┌─────────┐      ┌─────────┐        │ │
         └──┤   R3    ├──────┤   VFB   ├────────┼─┘
            └─────────┘      └─────────┘        │
                               │                │
                               │                │
                            ┌──┴─────────┐      │
                            │            │      │
         VOUT ──────────────┤     R4     ├──────┘
                            │            │
                            └────────────┘
                                │
                                │
                    ┌───────────┴───────────┐
                    │                       │
              ┌─────┴─────┐          ┌─────┴─────┐
              │    +IN    │          │    -IN    │
              │           │          │           │
              │   [ОУ]    ├──────────┤   VOUT    │
              │           │          │           │
              └───────────┘          └───────────┘
                    │
                   VCC (15V)
                   VEE (-15V)
```

## Схема с ошибкой (текущая реализация)

```
                    ┌─────────┐
         VIN ───────┤   R1    ├────── N1 ──────┐
                    └─────────┘                │
                                               │
                    ┌─────────┐                │
         N1 ────────┤   C1    ├────── N2 ──────┼─┐
                    └─────────┘                │ │
                                               │ │
                    ┌─────────┐                │ │
         N2 ────────┤   R2    ├────── N3 ──────┼─┼─┐
                    └─────────┘                │ │ │
                                               │ │ │
                    ┌─────────┐                │ │ │
         N3 ────────┤   C2    ├────── 0 (GND)  │ │ │
                    └─────────┘                │ │ │
                                               │ │ │
         ╔═════════════════════════════════════╝ │ │
         ║                                       │ │
         ║  ┌─────────┐      ┌─────────┐        │ │
         ╚══┤   R3    ├──────┤   VFB   │        │ │
            └─────────┘      └─────────┘        │ │
                         ❌ ВИСЯЧИЙ УЗЕЛ!       │ │
                            (никуда не         │ │
                             подключен)        │ │
                                              │ │
         VOUT ────────────────────────────────┼─┘
                                              │
                            ┌─────────────────┘
                            │
                            │
                    ┌───────┴────────┐
                    │                │
              ┌─────┴─────┐    ┌─────┴─────┐
              │    +IN    │    │    -IN    │
              │           │    │           │
              │   [ОУ]    ├────┤   VOUT    │
              │           │    │           │
              └───────────┘    └───────────┘
                    │
                   N3 ❌ ОШИБКА: подключен напрямую к N3,
                                 а должен быть к VFB!
                    │
                   VCC (15V)
                   VEE (-15V)
```

## Обозначения

- **VIN** - входной сигнал
- **VOUT** - выходной сигнал
- **N1, N2, N3** - внутренние узлы схемы
- **VFB** - узел обратной связи (должен быть подключен к +IN ОУ)
- **R1, R2** - резисторы фильтрующей цепи (10 кОм)
- **C1, C2** - конденсаторы фильтрующей цепи (10 нФ)
- **R3, R4** - резисторы делителя обратной связи (10 кОм, 22 кОм)
- **[ОУ]** - операционный усилитель

## Указание ошибки

❌ **ОШИБКА:** 
- Узел **VFB** является "висячим" - он создан резисторами R3 и R4, но никуда не подключен
- Положительный вход операционного усилителя подключен напрямую к узлу **N3**, минуя цепь обратной связи
- В результате положительная обратная связь не работает, и фильтр не функционирует как задумано

✅ **ПРАВИЛЬНО:**
- Узел **VFB** должен быть подключен к положительному входу операционного усилителя
- Положительный вход ОУ должен быть подключен к **VFB**, а не к **N3** напрямую

## Упрощенная схема для понимания

### Что должно быть (правильно):

```
         N3 ──R3── VFB ──+IN[ОУ]── VOUT
                         │
         VOUT ───R4──────┘
```

### Что есть (с ошибкой):

```
         N3 ──R3── VFB  ❌ (ничего не подключено)
         │
         └──────────+IN[ОУ]── VOUT
         │
         VOUT ───R4───→ (в никуда, к VFB, но VFB не используется)
```

## Визуализация потока сигнала

### Правильный поток сигнала:

```
VIN → R1 → C1 → R2 → C2 → GND
           ↓
          N3 → R3 → VFB → +IN[ОУ] → VOUT
                          ↑
          VOUT ──── R4 ───┘
          
          (Обратная связь работает)
```

### Неправильный поток сигнала (с ошибкой):

```
VIN → R1 → C1 → R2 → C2 → GND
           ↓
          N3 ────────→ +IN[ОУ] → VOUT
          │
          └──R3──→ VFB ❌ (не используется)
          
          VOUT ───R4──→ VFB ❌ (не используется)
          
          (Обратная связь НЕ работает)
```

# Фильтр нижних частот Саллена-Ки с ошибкой

## Описание схемы

Фильтр Саллена-Ки нижних частот - это активный фильтр второго порядка, использующий операционный усилитель в качестве повторителя напряжения с положительной обратной связью через делитель напряжения.

### Правильная структура фильтра Саллена-Ки:

```
ВХОД → R1 → C1 → R2 → C2 → ЗЕМЛЯ
             ↓
            N3 ──→ R3 ──→ VFB ──→ +IN (ОУ)
             ↑                    ↓
            ВЫХОД ←─── ОУ ←─── -IN
              ↑
              └── R4 ──→ VFB
```

Где:
- **VFB** - узел обратной связи, подключенный к положительному входу ОУ
- **R3, R4** - формируют делитель напряжения для положительной обратной связи
- Коэффициент усиления: **K = 1 + R4/R3**

## Обнаруженная ошибка

### Тип ошибки: **Топологическая / Функциональная**

### Описание ошибки:

В схеме отсутствует соединение узла **VFB** (обратной связи) с положительным входом операционного усилителя. 

**Конкретно:**
1. Резистор **R3** подключен от узла **N3** к узлу **VFB** ✓
2. Резистор **R4** подключен от выхода **VOUT** к узлу **VFB** ✓
3. **НО:** Узел **VFB** никуда не подключен - он "висячий"! ✗
4. Операционный усилитель подключен с положительным входом напрямую к узлу **N3**, минуя цепь обратной связи ✗

В netlist операционный усилитель подключен как:
```
XOPAMP N3 0 VOUT VCC VEE VOUT OPAMP
```

Где:
- `N3` - положительный вход (подключен напрямую, вместо VFB!)
- `0` - отрицательный вход (заземлен)
- `VOUT` - выход
- `VCC, VEE` - питание

**Правильно должно быть:**
```
XOPAMP VFB 0 VOUT VCC VEE VOUT OPAMP
```

Где `VFB` - узел, к которому подключены R3 и R4, формирующие делитель напряжения для положительной обратной связи.

### Последствия ошибки:

1. **Нарушение принципа работы фильтра** - положительная обратная связь не работает
2. **Искажение частотной характеристики** - фильтр не будет иметь правильную АЧХ Баттерворта или Чебышева
3. **Неправильный коэффициент усиления** - не будет достигнут расчетный коэффициент усиления K = 1 + R4/R3 = 1 + 22k/10k = 3.2
4. **Возможная нестабильность** - схема может генерировать или работать непредсказуемо

### Правильное исправление:

**Вариант 1:** Подключить VFB к положительному входу ОУ:
```
XOPAMP VFB 0 VOUT VCC VEE VOUT OPAMP
```

**Вариант 2:** Убрать промежуточный узел VFB и подключить напрямую:
```
R3 N3 +IN_OPAMP 10k
R4 VOUT +IN_OPAMP 22k
XOPAMP +IN_OPAMP 0 VOUT VCC VEE VOUT OPAMP
```

### Расчетные параметры (при правильном подключении):

- **Частота среза:** fc ≈ 1 / (2π√(R1·R2·C1·C2)) ≈ 1 / (2π·10k·10n) ≈ 1.59 кГц
- **Коэффициент усиления:** K = 1 + R4/R3 = 1 + 22k/10k = 3.2
- **Характеристика:** Баттерворта (при K = 1.586) или близко к ней

### Дополнительные замечания:

В текущей схеме также присутствует проблема с подключением отрицательного входа ОУ к земле, что делает усилитель повторителем напряжения. В классическом фильтре Саллена-Ки отрицательный вход обычно подключен к выходу (единичное усиление) или через резистор обратной связи.

### Категория ошибки по классификации:

- **Тип:** Топологическая / Функциональная
- **Серьезность:** Высокая
- **Обнаружимость:** Легко обнаруживается при симуляции (неправильная АЧХ) или визуальной проверке схемы

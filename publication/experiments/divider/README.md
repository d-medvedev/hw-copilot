# Эксперименты с делителями напряжения

Этот раздел содержит эксперименты по анализу делителей напряжения с использованием LLM-агентов.

## 📁 Структура файлов

### Основные файлы:
- `voltage_divider_experiment_v3.py` - **Актуальная версия эксперимента**
  - 10 тестовых кейсов с различными типами ошибок
  - Поддержка BOM (Bill of Materials) для анализа компонентов
  - Структурированный вывод через OpenAI API
  - Метрики: Precision, Recall, F1-score

- `error_detection_results_v3.json` - **Результаты последнего запуска**
  - Детальные результаты анализа всех 10 кейсов
  - Сравнение LLM vs экспертный анализ
  - Метрики качества обнаружения ошибок

## 🎯 Цель экспериментов

Оценить способность LLM-агента обнаруживать различные типы ошибок в электронных схемах:

### Типы ошибок:
1. **Логические** - неправильная логика работы
2. **Топологические** - неправильные соединения  
3. **Функциональные** - не выполняет требуемую функцию
4. **Электрические** - нарушение электрических правил
5. **Номиналы** - неправильные значения компонентов
6. **Пропущенные элементы** - отсутствующие компоненты

## 🔬 Тестовые кейсы

1. **Корректный делитель 3.3В** - эталонная схема без ошибок
2. **Ошибка номинала R2** - неправильное выходное напряжение
3. **Превышение мощности** - превышение номинальной мощности резисторов
4. **Высокий ток потребления** - неприемлемый ток для батарейного питания
5. **Неправильное соотношение делителя** - логическая ошибка в расчете
6. **Перепутаны резисторы местами** - топологическая ошибка
7. **Отсутствие защитных элементов** - пропущенные компоненты
8. **Температурная нестабильность** - неподходящие компоненты (с BOM)
9. **Множественные ошибки** - комбинация различных проблем
10. **Граничный случай** - малое превышение допуска

## 💡 Ключевые особенности v3.0

- **BOM-анализ:** Поддержка спецификации компонентов для реалистичного анализа
- **Структурированный вывод:** Использование OpenAI Structured Output для надежного парсинга
- **Детальные метрики:** Precision, Recall, F1-score для каждого типа ошибок
- **Температурный анализ:** Проверка ТКС резисторов через BOM

# Быстрый старт: MCP интеграция для SGR агента

## 🎯 Что это дает?

Интеграция MCP инструмента для SPICE симуляции позволяет агенту:
- ✅ Проверять свои расчеты через моделирование
- ✅ Итеративно улучшать схему на основе результатов симуляции
- ✅ Повышать точность синтеза схем делителей напряжения

## 🚀 Быстрый тест

```bash
# 1. Проверка симулятора
python3 mcp_spice_server.py

# 2. Тест интеграции с SGR агентом
python3 sgr_agent_with_mcp.py
```

## 📋 Как это работает

1. **Агент синтезирует схему** → генерирует SPICE netlist
2. **MCP инструмент валидирует netlist** → проверяет синтаксис
3. **MCP инструмент симулирует схему** → получает реальные значения Vout, тока, мощности
4. **Сравнение с требованиями** → если точность недостаточна, агент корректирует схему
5. **Итерация** → процесс повторяется до достижения нужной точности

## 🔧 Использование в коде

```python
from sgr_agent_with_mcp import SGRAgentWithMCP
from voltage_divider_synthesis_experiment import create_synthesis_test_cases

# Создаем агента с MCP
agent = SGRAgentWithMCP()

# Берем тестовый случай
test_cases = create_synthesis_test_cases()
test_case = test_cases[0]  # Базовый делитель 3.3В

# Синтез с проверкой через симуляцию
result = agent.synthesize_with_verification(
    test_case, 
    model="sgr_agent",
    max_iterations=3  # Максимум 3 попытки улучшения
)

# Результаты
print(f"Валидность: {result['final_valid']}")
print(f"Итераций: {result['verification']['iterations']}")
if result['verification']['results']:
    last_sim = result['verification']['results'][-1].get('simulation')
    if last_sim:
        print(f"Vout (симуляция): {last_sim.get('vout')} В")
```

## 🔌 Интеграция с SGR агентом

SGR агент доступен по адресу `http://89.169.178.142:8010`.

Текущая реализация использует:
- **Промпт-подход**: Агент получает результаты симуляции в промпте и корректирует схему
- **Локальный Python симулятор**: Работает без установки ngspice

Для более точной симуляции можно:
1. Установить ngspice: `brew install ngspice` (macOS) или `apt-get install ngspice` (Linux)
2. Использовать удаленный MCP сервер через HTTP API

## 📝 Примечания

- MCP SDK опционален - код работает в standalone режиме
- Python симулятор упрощенный, но достаточен для делителей напряжения
- Для сложных схем рекомендуется ngspice

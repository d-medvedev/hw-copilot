# Пояснение: Mock vs Реальные прогоны в Notebook

## ❓ Что такое Mock?

**Mock (заглушка)** - это упрощенная версия функций, которая **НЕ делает реальные вызовы к LLM API**, а использует предопределенную логику для демонстрации работы эксперимента.

### В контексте этого notebook:

**Mock-режим (`use_mock=True`):**
- ❌ **НЕ вызывает** реальные LLM API (OpenAI, OpenRouter и т.д.)
- ✅ Использует **упрощенные алгоритмы** для обнаружения ошибок/синтеза схем
- ✅ Работает **без API ключей**
- ✅ **Бесплатно** и **быстро** (мгновенно)
- ✅ Подходит для **демонстрации структуры** эксперимента

**Реальный режим (`use_mock=False`):**
- ✅ **Делает реальные запросы** к LLM API
- ✅ Показывает **реальную производительность** моделей
- ⚠️ Требует **API ключи** (OpenAI, OpenRouter)
- ⚠️ Может быть **платным** (зависит от модели)
- ⏱️ Занимает **время** (секунды на каждый запрос)

## 🔍 Примеры различий

### Mock-режим (текущий в notebook):

```python
# Упрощенная логика - просто проверяет значения
if abs(divider.vout - 3.3) > 0.5:
    detected_errors.append("type_1_wrong_ratio")
```

### Реальный режим (в оригинальных скриптах):

```python
# Реальный вызов к LLM API
response = openai_client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": prompt}],
    response_format={"type": "json_schema", "schema": schema}
)
# LLM анализирует схему и возвращает структурированный ответ
```

## 📊 Сравнение

| Характеристика | Mock-режим | Реальный режим |
|----------------|------------|----------------|
| Вызовы к LLM | ❌ Нет | ✅ Да |
| API ключи | ❌ Не нужны | ✅ Обязательны |
| Стоимость | ✅ Бесплатно | ⚠️ Платно |
| Скорость | ✅ Мгновенно | ⏱️ Секунды на запрос |
| Точность | ⚠️ Упрощенная | ✅ Реальная |
| Назначение | Демонстрация | Реальные эксперименты |

## 🚀 Как использовать реальные прогоны?

### Вариант 1: В notebook

1. Установите API ключ:
   ```python
   import os
   os.environ["OPENAI_API_KEY"] = "sk-..."
   # или
   os.environ["OPENROUTER_API_KEY"] = "sk-..."
   ```

2. Измените `USE_MOCK = False` в ячейке запуска

3. Замените `SimpleAnalysisAgent` и `SimpleSynthesisAgent` на полные версии из оригинальных скриптов

### Вариант 2: Используйте оригинальные скрипты

Для **реальных экспериментов** используйте:
- `voltage_divider_experiment_v4.py` - анализ с реальными LLM
- `voltage_divider_synthesis_experiment.py` - синтез с реальными LLM

Эти скрипты уже настроены для работы с реальными API.

## 💡 Зачем нужен Mock в notebook?

1. **Демонстрация** - показать структуру эксперимента без затрат
2. **Обучение** - понять логику работы без необходимости API ключей
3. **Тестирование** - проверить визуализации и метрики
4. **Доступность** - любой может запустить notebook без настройки API

**Текущий notebook использует MOCK для демонстрации.**

Для **реальных результатов** используйте оригинальные скрипты или адаптируйте notebook с полными версиями агентов.

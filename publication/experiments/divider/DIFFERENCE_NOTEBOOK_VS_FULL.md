# Разница между Notebook и Полной версией

## 📝 Фраза: "В реальном эксперименте используется полная версия с API"

Эта фраза означает, что в notebook используется **упрощенная версия** агента для демонстрации, а в оригинальных скриптах (`voltage_divider_experiment_v4.py` и `voltage_divider_synthesis_experiment.py`) используется **полная версия** с расширенными возможностями.

## 🔍 Основные различия

### 1. **Structured Output (JSON Schema)**

**Полная версия:**
- Использует `response_format={"type": "json_schema", "schema": {...}}`
- Гарантирует структурированный JSON ответ от LLM
- Автоматическая валидация формата ответа
- Fallback на обычный JSON парсинг если structured output не поддерживается

**Упрощенная версия (notebook):**
- Простой промпт с просьбой вернуть JSON
- Ручной парсинг JSON из текста
- Менее надежно

### 2. **Детальность промптов**

**Полная версия:**
- Очень детальные промпты (400+ строк)
- Четкие критерии для каждого типа ошибки
- Примеры правильных и неправильных случаев
- Инструкции по разделению ошибок и предупреждений
- Обработка граничных случаев

**Упрощенная версия (notebook):**
- Базовый промпт (~20 строк)
- Упрощенные критерии
- Подходит для демонстрации, но менее точна

### 3. **Поддержка провайдеров**

**Полная версия:**
- Поддержка OpenAI и OpenRouter
- Автоматическое определение провайдера
- Настройка base_url для OpenRouter
- Поддержка разных моделей через конфигурацию

**Упрощенная версия (notebook):**
- Только OpenAI (можно расширить)
- Фиксированная модель `gpt-4o-mini`

### 4. **Обработка ошибок и таймаутов**

**Полная версия:**
- Таймауты: 60s на подключение, 120s на чтение
- Обработка `APITimeoutError`
- Retry логика при ошибках structured output
- Детальное логирование ошибок

**Упрощенная версия (notebook):**
- Базовая обработка исключений
- Нет таймаутов
- Простые сообщения об ошибках

### 5. **BOM и Load Info**

**Полная версия:**
- Полная поддержка BOM (Bill of Materials)
- Анализ характеристик компонентов из BOM
- Учет информации о нагрузке (load_info)
- Проверка соответствия компонентов требованиям

**Упрощенная версия (notebook):**
- Базовая поддержка (поля есть, но логика упрощена)

### 6. **Валидация и метрики**

**Полная версия:**
- Детальная валидация каждого аспекта схемы
- Подсчет метрик по типам ошибок
- Сравнение с экспертными оценками
- Генерация подробных отчетов

**Упрощенная версия (notebook):**
- Базовая валидация
- Упрощенные метрики

## 📊 Сравнительная таблица

| Функция | Notebook (упрощенная) | Полная версия |
|---------|----------------------|---------------|
| Structured Output | ❌ Нет | ✅ Да (JSON Schema) |
| Детальные промпты | ⚠️ Базовые | ✅ Очень детальные |
| Поддержка провайдеров | ⚠️ Только OpenAI | ✅ OpenAI + OpenRouter |
| Таймауты | ❌ Нет | ✅ Да (60s/120s) |
| BOM анализ | ⚠️ Упрощенный | ✅ Полный |
| Обработка ошибок | ⚠️ Базовая | ✅ Расширенная |
| Метрики | ⚠️ Базовые | ✅ Детальные |
| Конфигурация моделей | ❌ Нет | ✅ Да (JSON) |

## 🎯 Когда использовать что?

### Notebook (упрощенная версия):
- ✅ Демонстрация концепции
- ✅ Обучение и понимание структуры
- ✅ Быстрое тестирование
- ✅ Работа без сложной настройки

### Полная версия (оригинальные скрипты):
- ✅ Реальные эксперименты
- ✅ Публикация результатов
- ✅ Сравнение моделей
- ✅ Детальный анализ
- ✅ Научные исследования

## 💡 Пример различий в коде

### Упрощенная версия (notebook):
```python
prompt = f"""Проанализируй схему делителя напряжения.
ТЗ: {test_case.requirements}
Схема: R1={r1}, R2={r2}, Vin={vin}
Ответь в формате JSON."""
```

### Полная версия (оригинальный скрипт):
```python
prompt = f"""Ты - опытный инженер-электронщик. Проанализируй схему...

[400+ строк детальных инструкций]

КРИТЕРИИ:
- Type 2: R_total < 100 Ом → ВСЕГДА ошибка
- Type 3: R_total >= 10 МОм → ВСЕГДА ошибка
- Граничные случаи: R_total = 100 Ом → ОШИБКА
...

[много деталей]"""

# С structured output
response = client.chat.completions.create(
    model=model_name,
    messages=[{"role": "user", "content": prompt}],
    response_format={"type": "json_schema", "schema": response_schema}
)
```

## 🔄 Как перейти на полную версию?

Если хотите использовать полную версию в notebook:

1. **Импортируйте классы из оригинальных скриптов:**
   ```python
   from voltage_divider_experiment_v4 import CircuitAnalysisAgentV4
   from voltage_divider_synthesis_experiment import DividerSynthesisAgent
   ```

2. **Используйте их вместо SimpleAnalysisAgent:**
   ```python
   agent = CircuitAnalysisAgentV4(
       model_name="gpt-4o-2024-08-06",
       api_provider="openai"
   )
   ```

3. **Или скопируйте полные классы в notebook**

## 📝 Итог

**"Полная версия с API"** означает:
- Более надежная работа с LLM (structured output)
- Детальные промпты для лучшей точности
- Расширенная функциональность (BOM, load_info, метрики)
- Профессиональная обработка ошибок
- Поддержка различных провайдеров и моделей

**Упрощенная версия в notebook** - это демонстрация концепции, которая работает, но не имеет всех возможностей полной версии.

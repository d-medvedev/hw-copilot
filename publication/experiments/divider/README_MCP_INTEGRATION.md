# Интеграция MCP инструмента для SPICE симуляции

Этот документ описывает, как подключить MCP (Model Context Protocol) инструмент для моделирования схем к SGR агенту для повышения точности расчетов.

## 🎯 Цель

Позволить агенту проверять свои расчеты через SPICE симуляцию, что повышает точность синтеза схем делителей напряжения.

## 📁 Файлы

- `mcp_spice_server.py` - MCP сервер с инструментами для SPICE симуляции
- `sgr_agent_with_mcp.py` - Интеграция SGR агента с MCP инструментом
- `test_sgr_agent.py` - Базовый клиент для SGR агента

## 🚀 Установка

### Вариант 1: Локальный Python симулятор (рекомендуется для начала)

```bash
# Установка зависимостей
pip install mcp

# Запуск теста
python3 sgr_agent_with_mcp.py
```

### Вариант 2: С ngspice (для более точной симуляции)

```bash
# Установка ngspice (macOS)
brew install ngspice

# Или через apt (Linux)
sudo apt-get install ngspice

# Проверка установки
ngspice --version
```

## 🔧 Использование

### Базовое использование

```python
from sgr_agent_with_mcp import SGRAgentWithMCP
from voltage_divider_synthesis_experiment import create_synthesis_test_cases

# Создаем агента с MCP
agent = SGRAgentWithMCP()

# Берем тестовый случай
test_cases = create_synthesis_test_cases()
test_case = test_cases[0]

# Синтез с проверкой через симуляцию
result = agent.synthesize_with_verification(
    test_case, 
    model="sgr_agent",
    max_iterations=3  # Максимум 3 попытки улучшения
)

print(f"Валидность: {result['final_valid']}")
print(f"Итераций: {result['verification']['iterations']}")
```

### Интеграция с SGR агентом через HTTP API

Если SGR агент поддерживает вызов внешних инструментов через HTTP:

```python
# Настройка MCP сервера как HTTP API
agent = SGRAgentWithMCP(
    base_url="http://89.169.178.142:8010",
    mcp_server_url="http://localhost:8080"  # MCP HTTP API
)
```

## 📊 Как это работает

1. **Синтез схемы**: Агент генерирует схему делителя напряжения
2. **Валидация netlist**: Проверяется синтаксис SPICE netlist
3. **Симуляция**: Выполняется DC анализ схемы
4. **Проверка точности**: Сравнивается выходное напряжение с требуемым
5. **Коррекция (при необходимости)**: Если точность недостаточна, агент получает обратную связь и корректирует схему

## 🛠️ Доступные инструменты MCP

### 1. `simulate_circuit`

Выполняет DC симуляцию схемы делителя напряжения.

**Параметры:**
- `netlist` (обязательно): SPICE netlist схемы
- `vin` (опционально): Входное напряжение в Вольтах

**Возвращает:**
```json
{
  "success": true,
  "vout": 3.3,
  "current_ma": 0.5,
  "power_r1_mw": 4.35,
  "power_r2_mw": 1.09,
  "r_out": 2200.0,
  "r1": 6600.0,
  "r2": 3300.0,
  "vin": 12.0
}
```

### 2. `validate_netlist`

Проверяет синтаксис SPICE netlist.

**Параметры:**
- `netlist` (обязательно): SPICE netlist для проверки

**Возвращает:**
```json
{
  "valid": true,
  "errors": [],
  "warnings": []
}
```

## 🔌 Интеграция с SGR агентом

SGR агент может использовать эти инструменты двумя способами:

### Способ 1: Через промпт (текущая реализация)

Агент получает результаты симуляции в промпте и корректирует схему на основе обратной связи.

### Способ 2: Через tool calling (если поддерживается)

Если SGR агент поддерживает вызов инструментов, можно настроить их в конфигурации агента:

```python
# Пример конфигурации для SGR агента
tools_config = {
    "tools": [
        {
            "name": "simulate_circuit",
            "description": "Выполняет SPICE симуляцию схемы",
            "endpoint": "http://localhost:8080/tools/simulate_circuit"
        },
        {
            "name": "validate_netlist",
            "description": "Проверяет синтаксис netlist",
            "endpoint": "http://localhost:8080/tools/validate_netlist"
        }
    ]
}
```

## 📈 Преимущества

1. **Повышение точности**: Агент может проверить свои расчеты через симуляцию
2. **Итеративное улучшение**: Возможность корректировать схему на основе результатов симуляции
3. **Валидация**: Проверка корректности netlist перед симуляцией

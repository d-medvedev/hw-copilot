# Предложения по графической визуализации результатов эксперимента

## 📊 Рекомендуемые графики

### 1. **Radar Chart (Паутинная диаграмма) - F1-score по типам ошибок**
**Назначение:** Показать сильные и слабые стороны каждой модели

**Структура:**
- 8 осей (по одной на каждый тип ошибки)
- 12 линий (по одной на каждую модель)
- Цветовая кодировка: коммерческие (синий), open-source крупные (зеленый), open-source малые (оранжевый)

**Преимущества:**
- Легко видеть, какие типы ошибок модель обнаруживает лучше всего
- Сравнение моделей на одном графике
- Выявление паттернов (например, все модели хорошо справляются с Type 1, но плохо с Type 3)

---

### 2. **Bar Chart (Столбчатая диаграмма) - Общие метрики (Precision, Recall, F1)**
**Назначение:** Сравнение моделей по основным метрикам

**Структура:**
- Группированные столбцы для каждой модели
- 3 столбца на модель: Precision (синий), Recall (зеленый), F1-score (оранжевый)
- Модели отсортированы по F1-score (от лучшей к худшей)
- Горизонтальные линии для разделения групп (commercial/opensource)

**Преимущества:**
- Быстрое сравнение всех моделей
- Видно баланс между Precision и Recall
- Легко определить лучшие модели

---

### 3. **Heatmap (Тепловая карта) - F1-score по типам ошибок**
**Назначение:** Детальный анализ производительности по типам ошибок

**Структура:**
- Строки: модели (отсортированы по общему F1-score)
- Столбцы: типы ошибок (Type 1-8)
- Цветовая шкала: от красного (0.0) через желтый (0.5) до зеленого (1.0)
- Аннотации: числовые значения F1-score в каждой ячейке

**Преимущества:**
- Легко видеть паттерны (какие типы ошибок сложны для всех моделей)
- Выявление специализации моделей
- Компактное представление большого объема данных

---

### 4. **Scatter Plot (Диаграмма рассеяния) - Precision vs Recall**
**Назначение:** Анализ баланса между точностью и полнотой

**Структура:**
- Ось X: Recall
- Ось Y: Precision
- Точки: модели (размер точки = F1-score)
- Цветовая кодировка: группа модели (commercial/opensource)
- Размер точки: F1-score
- Идеальная точка: (1.0, 1.0) в правом верхнем углу

**Преимущества:**
- Видно, какие модели склонны к ложным срабатываниям (высокий Precision, низкий Recall)
- Видно, какие модели склонны к пропускам (низкий Precision, высокий Recall)
- Легко определить оптимальный баланс

---

### 5. **Grouped Bar Chart - Сравнение по группам моделей**
**Назначение:** Сравнение коммерческих vs open-source моделей

**Структура:**
- 3 группы: Commercial Large, Open-source Large, Open-source Small
- В каждой группе: средние значения Precision, Recall, F1
- Столбцы с доверительными интервалами (если есть несколько моделей в группе)

**Преимущества:**
- Показывает, какая группа моделей лучше
- Легко увидеть влияние размера модели
- Подходит для научных публикаций

---

### 6. **Stacked Bar Chart - Распределение TP/FP/FN**
**Назначение:** Детальный анализ ошибок классификации

**Структура:**
- Горизонтальные столбцы для каждой модели
- 3 сегмента: True Positives (зеленый), False Positives (желтый), False Negatives (красный)
- Общая длина столбца = общее количество ошибок в тестах

**Преимущества:**
- Видно, сколько ошибок найдено правильно
- Видно количество ложных срабатываний и пропусков
- Легко сравнить модели

---

### 7. **Line Chart - F1-score по типам ошибок (для топ-5 моделей)**
**Назначение:** Показать производительность лучших моделей детально

**Структура:**
- Ось X: типы ошибок (Type 1-8)
- Ось Y: F1-score (0.0-1.0)
- 5 линий для топ-5 моделей
- Легенда с названиями моделей

**Преимущества:**
- Детальное сравнение лучших моделей
- Видно, на каких типах ошибок модели различаются
- Легко читается

## Аннотация

В работе представлена система машинного обучения для автоматического анализа качества технических заданий в области электроники. Предложен подход к синтетической генерации датасета технических требований с контролируемыми типами ошибок. Разработана архитектура системы, включающая извлечение технических параметров, классификацию полноты требований и генерацию рекомендаций по улучшению. Экспериментальная оценка показала точность классификации 78% и полноту извлечения параметров 72%.

**Ключевые слова:** машинное обучение, техническое задание, обработка естественного языка, электроника, автоматизация проектирования.

## 1. Введение

Качество технического задания критически влияет на успешность проектирования электронных устройств. Неполные, противоречивые или неточные требования приводят к ошибкам проектирования, увеличению сроков разработки и дополнительным затратам.

### 1.1 Проблематика

Типичные проблемы технических заданий:
- **Неполнота** - отсутствие критически важных параметров
- **Противоречивость** - конфликтующие требования  
- **Неопределенность** - размытые формулировки
- **Отсутствие контекста** - неучтенные условия эксплуатации

### 1.2 Цель исследования

Разработка системы машинного обучения для автоматического анализа и улучшения качества технических заданий в области электроники.

## 3. Методология

### 3.1 Архитектура системы

Система включает следующие компоненты:
1. **Модуль извлечения параметров** - NLP обработка текста ТЗ
2. **Классификатор полноты** - ML модель оценки качества
3. **Генератор рекомендаций** - система улучшения ТЗ

### 3.2 Синтетическая генерация датасета

Для обучения системы разработан подход к созданию синтетического датасета:
- Шаблоны ТЗ для разных типов устройств
- Контролируемое внесение ошибок
- Автоматическая разметка проблем

## 4. Эксперименты

- Уровни качества: хорошие, неполные, противоречивые

### 4.2 Метрики

- Точность классификации полноты ТЗ

# Публикация в журнале "Доклады ТУСУР"

Этот раздел содержит все материалы для подготовки научной статьи по теме **"Оценка точности и достоверности анализа принципиальных электрических схем специализированным LLM-агентом"**.

## 🎯 Цель исследования

Оценить способность LLM-агента, оснащенного инженерными инструментами, к анализу электронных схем и выявлению ошибок в сравнении с экспертными заключениями инженеров.

## 🔬 Методология исследования

### Подход
Постепенное наращивание сложности схем от простых пассивных элементов к преобразовательной технике и силовой электронике.

### Этапы экспериментов
1. **Делители напряжения** (текущий фокус) - отладка базовой концепции
2. **Пассивные фильтры RC/LC** - анализ частотных характеристик
3. **Линейные стабилизаторы (LDO)** - схемы с активными компонентами

## 📊 Текущие результаты

### Эксперимент с делителями напряжения (v3.0)
- **Тестовых кейсов:** 10
- **F1-score:** 0.61
- **Precision:** 0.64
- **Recall:** 0.58
- **Успешность анализа:** 100% (10/10)

### Типы обнаруживаемых ошибок
1. **Логические** - неправильная логика работы
2. **Топологические** - неправильные соединения
3. **Функциональные** - не выполняет требуемую функцию
4. **Электрические** - нарушение электрических правил
5. **Номиналы** - неправильные значения компонентов
6. **Пропущенные элементы** - отсутствующие компоненты

## 🛠️ Инструменты LLM-агента

### Реализованные:
- **Netlist-parser** - структурирование схемы
- **BOM-анализ** - проверка характеристик компонентов
- **Structured Output** - надежное извлечение результатов

### Планируемые:
- **SPICE-симулятор** - численный анализ (DC, AC, Transient)
- **ERC/DRC-модуль** - проверка инженерных правил
- **RAG-система** - доступ к даташитам и стандартам

## 🎯 Ключевые достижения

### Технические инновации:
1. **BOM-интеграция** - анализ реальных компонентов с их характеристиками
2. **Структурированный вывод** - 100% надежность парсинга результатов
3. **Многоуровневая классификация ошибок** - 6 категорий с детальным анализом
4. **Температурный анализ** - проверка ТКС резисторов через спецификацию

### Научная новизна:
- Первое систематическое исследование LLM в анализе схем
- Количественные метрики качества (Precision, Recall, F1)
- Сравнение с экспертными заключениями
- Реалистичные сценарии использования (BOM + netlist + ТЗ)

## 📈 Метрики и оценка

### Основные метрики:
- **Precision** - доля правильно обнаруженных ошибок
- **Recall** - доля найденных ошибок от общего количества
- **F1-score** - гармоническое среднее Precision и Recall
- **Cohen's κ** - уровень согласия с экспертом

### Детальная аналитика:
- Анализ по типам ошибок
- Ложные срабатывания и пропуски
- Сравнение с экспертными оценками
- Влияние BOM на качество анализа

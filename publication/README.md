# Публикация в журнале "Доклады ТУСУР"

## Тема исследования
Система автоматического анализа и улучшения технических заданий для электронных устройств с применением машинного обучения

## Структура публикации

### 📄 paper/
- `draft.md` - Черновик статьи
- `final.docx` - Финальная версия для подачи
- `reviews/` - Рецензии и правки

### 🧪 experiments/
- Код экспериментов
- Скрипты для воспроизведения результатов
- Jupyter notebooks с анализом

### 📊 data/
- Датасеты для экспериментов
- Результаты тестирования
- Метрики и статистика

### 📈 figures/
- Графики и диаграммы
- Схемы архитектуры
- Визуализации результатов

### 📚 references/
- Библиография
- Источники и стандарты
- Релевантные публикации

## Требования журнала "Доклады ТУСУР"
- Объем: 6-8 страниц
- Формат: ГОСТ 7.89-2005
- Язык: русский
- Рецензирование: двойное слепое
- Индексация: РИНЦ, ВАК
